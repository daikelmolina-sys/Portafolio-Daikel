# 🚀 Repositorio Multi-Proyecto

Este repositorio contiene 3 proyectos de desarrollo web y aplicaciones:

---

## 📂 Proyectos Incluidos

### 1. 🍱 Gastronomía — Onigiri POS (`pagina Gastronomia/onigiri-pos`)
* **Descripción:** Sistema de punto de venta (POS) y gestión para restaurante japonés (Onigiri).
* **Tecnologías:** PHP 8.2+ / Laravel 12 / Vite / Blade / MySQL / Docker.
* **Instalación rápida:**
  ```bash
  cd "pagina Gastronomia/onigiri-pos"
  composer install
  npm install
  npm run build
  php artisan serve
  ```

---

### 2. 🔮 Omnidex — Enciclopedia Pokémon (`pagina Omnidex/omnidex-app`)
* **Descripción:** Enciclopedia interactiva y futurista de Pokémon con interfaz holográfica y animaciones fluidas.
* **Tecnologías:** HTML5, CSS3 (Glassmorphism), JavaScript Vanilla, Docker / Nginx.
* **Ejecución rápida:**
  * Abrir `pagina Omnidex/omnidex-app/index.html` en el navegador o ejecutar con `docker-compose up -d`.

---

### 3. ⚽ Fútbol Estadística (`pagina futbol estadistica`)
* **Descripción:** Portal y API para el cálculo automático de tablas de posiciones, jornadas y estadísticas de torneos de fútbol.
* **Tecnologías:** PHP / Laravel / Blade / TailwindCSS / SQLite / MySQL.
* **Instalación rápida:**
  ```bash
  cd "pagina futbol estadistica"
  composer install
  npm install
  php artisan serve
  ```
